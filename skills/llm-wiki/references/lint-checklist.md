# Lint Checklist

Wiki の健全性チェック項目。**破壊的編集はしない**。レポートとして出力し、ユーザの判断で個別に修正する。

## チェック項目

### 1. 壊れた wikilink
- `[[ノート名]]` で参照されているが、対応するファイル（または alias）が存在しないもの
- Grep で `\[\[([^\]]+)\]\]` を抽出 → 実ファイル／フロントマターの `aliases` と突き合わせ

### 2. 孤立ページ
- `wiki/pages/` のファイルのうち、どこからも wikilink されていないもの
- `topics/` からも index.md からもリンクされていないページは要確認

### 3. index.md の網羅性
- `wiki/pages/` と `wiki/topics/` の全ファイルが `wiki/index.md` に登録されているか
- 逆に、index.md が参照しているのに実ファイルが無いエントリ

### 4. 古い更新日付
- `updated` が現在から6ヶ月以上経過しているページ
- 変化の早いトピック（技術・業界動向など）は注意喚起

### 5. 未解決 Open Questions
- `## Open Questions` セクションに項目が残っているページを一覧化
- 長期間放置されているものは優先的に報告

### 6. ページ間の矛盾
- 同じエンティティに関する記述が複数ページで食い違っていないか
- 候補検出はキーワードベース（完全自動は難しい）、気づいたものを挙げる

### 7. フロントマター欠損
- `created` / `updated` / `tags` / `sources` のいずれかが欠けているページ
- 必須キーの標準形から外れているもの

### 8. タグの揺れ
- 似たタグが別表記で乱立（例: `ai` と `AI`, `llm` と `LLM`, `機械学習` と `ML`）

## 出力フォーマット

Markdown のセクション別レポートとして返す:

```markdown
## Lint Report — YYYY-MM-DD

### 壊れた wikilink (N件)
- [[foo]] referenced in [[bar]]：対応ファイル無し

### 孤立ページ (N件)
- [[orphan-note]]

（以下同様）

### 推奨アクション
1. ...
2. ...
```

## log.md 追記

```
YYYY-MM-DD HH:MM [lint] 壊れlink N, 孤立 M, 矛盾 K, OpenQ L
```
